# Flight-Fare-Prediction
Machine learning regression models to predict flight ticket prices using Python, scikit-learn, and XGBoost.


# ✈️ Flight Price Prediction

## 📌 Problem Statement
Airfare prices fluctuate based on multiple factors such as airline, route, duration, and time of travel. This project aims to **predict flight ticket prices** using historical flight data and machine learning regression models.

---

## 📊 Dataset
- Historical flight booking data  
- Features include airline, source, destination, duration, total stops, and travel date  
- Supervised regression dataset  

*(Dataset source can be added if external, e.g., Kaggle)*

---

## ⚙️ Approach
- Data cleaning and preprocessing  
- Categorical feature encoding  
- Feature scaling  
- Train-test split  
- Model training and comparison  
- Performance evaluation using regression metrics  

---

## 🤖 Models Used
- Linear Regression  
- Support Vector Regression (SVR)  
- XGBoost Regressor  

---

## 📈 Evaluation Metrics
- Mean Squared Error (MSE)  
- Root Mean Squared Error (RMSE)  
- R² Score  

---

## ✅ Results
- Compared multiple regression models  
- XGBoost demonstrated better prediction performance  
- Identified key factors influencing flight prices  

---
